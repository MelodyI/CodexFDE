# L04｜委托 Codex 执行一次最小变更

本课程的任务是完成一次自举换挡：先建设并独立验收个人工作台 V0，再由 V0 读取 L03 的确认版 Spec，组织 Codex 交付 FlowERP 库存导出。

建议按以下顺序使用本目录材料：

1. `阅读讲义.md`：理解两张 Ticket、工作台 V0 架构、执行边界和三类判断。
2. `实践操作手册.md`：完成 Ticket A 建设与独立验收，再执行并复验 Ticket B。
3. `prompts`：分阶段与 Codex 协作，不一次性交出全部判断。
4. `行动卡.md`：提交前逐项核对。
5. [controlled-delivery-handoff skill](skills/controlled-delivery-handoff/SKILL.md)：依据前序规则与 Spec 补齐 V0，指导复验、首次客户执行和过程截图；个人判断与结果直接保存在已有任务记录中。

课堂演示使用 [L04 图文案例版（30 页）](slides/L04-委托Codex执行一次最小变更-图文案例版-30页-交付边界标题修订.pptx)。Word 版讲义和手册分别为 `L04-阅读讲义.docx`、`L04-实践操作手册.docx`。

参考仓库中的终态、测试和示例记录用于理解目标，不能代替个人建设、独立复验和实际审核。

新版 PPT 用 9 组案例展开具体输入与结果，包含工作台页面、实际参考错误记录、流程图和库存前后对照图。案例页码与讲义对应见[课堂索引](../教师资料/L04/slides/PPT大纲.md)。

第 12～16 页结合真实参考截图、源码断言和教学反例，讲清事项与任务的关系、检查与人审的分工、用例覆盖边界、执行前置验收，以及代码变更后的重新复验。教学推演与实际执行记录分别标明。
