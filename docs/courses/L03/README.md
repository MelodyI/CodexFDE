# L03｜把模糊需求变成可验收 Spec

本讲先看工作台架构，再把库存导出需求写成可审查的合同，并建设最小解析器。库存导出业务由 L04 实现。

按下面的顺序使用材料：

1. 阅读[讲义](辅导资料.md)，配合[课堂 PPT](slides/L03-把模糊需求变成可验收Spec-课堂重建版-架构与设计思想.pptx)理解案例与方法。
2. 按[实践操作手册](实践操作手册.md)完成自己的需求澄清、Spec 与解析器；执行时用[行动卡](行动卡.md)核对遗漏。
3. 用[提交模板](SUBMISSION.md)整理真实决定、修订、运行与反馈。

本讲最终应留下三项可复用成果：实际确认的库存合同、能起草不同需求的六部分模板、已接入工作台入口的个人解析器。课堂先理解主线，完整编码、同伴审查与迁移在实践环节完成。

实践需要的 Prompt、审查 skill、候选与修订样稿均在相应步骤中链接，使用到时再打开。三份 Prompt 不是附加练习：它们依次把工作台建设到 `contract_ready → gateway_connected → handoff_ready`，并明确证明 L04 会消费同一份确认版合同。插图随讲义阅读，不需要单独学习。课件仅保留当前版本。

配套资料：[辅导资料](辅导资料.md)、[实践操作手册](实践操作手册.md)，可按需查阅。
