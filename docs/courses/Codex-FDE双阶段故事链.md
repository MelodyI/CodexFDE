# Codex 与 FDE 的双阶段故事链

用 Codex，搭建个人 AI 研发工作台；通过工作台组织人与 AI 协同，持续开发 FlowERP。

L01～L03，林舟直接监督 Codex，先建立需求和命令记录，再明确仓库规则与可验收 Spec。L04 先独立验收 Workbench V0，再由这套工作台组织库存导出交付；工作台建设与客户交付分别保留证据。

L05 起，周宁提出的库存、订单与采购问题持续推动工作台升级。林舟与 Codex补充检查、故障处理和协作能力，再通过工作台组织受控执行，陈珂对照候选、报告与业务结果独立复验。反馈回到后续事项，并不自动成为新规则。

L16 从此前未实现的小需求检验迁移能力，保留真实运行、失败、修订及具名审核。人物对话是教学设计，不能代替学生本人的学习记录。
