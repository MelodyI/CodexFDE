# L06｜用 Harness 汇总证据和等级

当前唯一任务卡入口：[L06 行动卡](../L06/行动卡.md)。执行步骤以 [实践操作手册](../L06/实践操作手册.md) 为准，避免维护第二套命令。

产品增量：统一查询和 CSV 的可用量，拒绝超额预占并保持库存状态。工作台增量：统一登记与运行 L05 检查，建立可解释的等级、时间、原因、JSON 和退出码。跨入口业务风险用来验证这项工作台能力。

你确认口径与等级，Codex 在两个实现文件内修复，独立合同检查新增 Harness，实际写入核对保护六份冻结检查，复验者与审核者作真实判断。默认单项课程检查不足以覆盖当前手册，须按手册显式追加四项。

通过标准：阻断失败返回非零；观察失败记录告警；报告保留时间和失败原因。学习证据包括首次预测、真实失败、修订、原检查复验、换输入与人员反馈，参考绿灯不替代你的证据。

- **核心内容**：用例发现、统一退出码、阻断级与观察级指标、机器可读报告。
- **演示结果**：Harness 输出分项结果、阻断结论和 JSON 报告。
- **课内增量**：实现最小 Harness，将第 5 讲用例纳入统一执行。
- **通过标准**：阻断用例失败时返回非零退出码；观察项失败只记录告警；报告保留运行时间和失败原因。
