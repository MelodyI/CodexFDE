# L15 维护案例：空库存也应有导出列名

> 历史材料：本文于 2026-09-14 从课程标签对应的 Git 对象 `80d90b2` 恢复。下文记录原维护运行，不是本次排查重新执行的结果；该运行目录、任务报告和当前独立 FlowERP 行为须另行核对。

维护者实际调用库存导出时发现：没有库存记录，得到的是空字符串。使用者难以分辨“没有数据”和“导出格式有问题”。本次将需求限定为：空库存返回固定列名，不新增库存、不改变权限，也不扩展其他导出类型。

修复前是空字符串；修复后 CSV 内容为一行列名：

```csv
sku,name,site,location,lot_id,on_hand,reserved,available
```

有库存时仍输出原来的数据；没有报告权限时拒绝导出；另一个组织只看到自己的结果；未知导出类型仍被拒绝。导出前后的库存记录应一致。
