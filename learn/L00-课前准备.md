# Codex-01-学习目标
**搭建基于Spec的AI全流程开发环境**

## 资料

### 阶段
| 阶段             | 你逐渐能做的事                                  | 看得见的成果                                   |
| ---------------- | ----------------------------------------------- | ---------------------------------------------- |
| 第一周，L01～L04 | 说清范围，让 Codex 在边界内工作，并保存检查记录 | 最小工作台；L04 第一次交付库存导出             |
| 第二周，L05～L08 | 用正常与失败例子检查结果，在本机与远端重复检查  | 幂等入库、库存口径、订单创建与原子预占逐步完善 |
| 第三周，L09～L12 | 安排返工与分工，知道何时停止、何时交给人审核    | 订单取消与状态修复、采购申请及审批后入库       |
| 第四周，L13～L16 | 使用界面、处理反馈，让他人也能启动和检查交付    | 可操作的工作台与 FlowERP，完成一个现场新需求   |


### 三个名字
| 名字               | 你可以怎样理解                                       | 课程里由谁来建设、使用                                  |
| ------------------ | ---------------------------------------------------- | ------------------------------------------------------- |
| Codex              | 与你一起工作的 AI 开发伙伴，可以理解项目并使用工具   | 你提出目标、检查计划和结果，Codex 协助调查与实现        |
| 个人 AI 研发工作台 | 组织研发工作的地方，记录需求、任务、修改、检查和审核 | 你先与 Codex 一起搭建，随后用它组织交付                 |
| FlowERP            | 电商客户使用的软件，逐步管理进货、销售、库存和财务   | 你通过工作台与 Codex 协作开发，用真实业务结果检验工作台 |

| 工具    | 它在你电脑上做什么             | 你今天会用到的功能               |
| ------- | ------------------------------ | -------------------------------- |

## 实操

### 建立环境（只需一次）
```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -e .

# 环境检查
.venv/bin/python -X utf8 -m workbench.cli environment-check
.venv/bin/python -X utf8 -m eval.harness --suite blocking
.venv/bin/python -X utf8 -m workbench.cli environment-check --product
```
### 启动（本仓根目录，一条命令起两个服务）
```bash
python3 main.py                 # 8001 工作台 + 8000 FlowERP
python3 main.py --reuse         # 保留已有工作台进程，避免换到空目录
python3 main.py --open-browser  # 自动打开浏览器
python3 main.py --stop          # 停止（可选 workbench / flowerp）
```
### 只开工作台
```bash
.venv/bin/python -X utf8 -m workbench.cli serve-workbench --enable-code-execution
```
### 课程跟跑
```bash
.venv/bin/python -X utf8 -m workbench.cli course-status
.venv/bin/python -X utf8 -m workbench.cli course-contract --lesson N
.venv/bin/python -X utf8 -m workbench.cli course-eval --lesson N
```
### 编排（各自必须有停止条件）
```bash
.venv/bin/python -X utf8 -m agent.loop --max-rounds 3
.venv/bin/python -X utf8 -m agent.graph --max-rounds 3
```

### 核对工作台实际运行目录与数据库
```bash
curl -s http://127.0.0.1:8001/api/health
```
